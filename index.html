Dependabot checks supported dependencies against the GitHub Advisory Database and opens the pull request that fixes them.

  • Alerts for vulnerable dependencies in supported ecosystems, plus malware alerts for npm, pip, Maven, NuGet, Go, Composer, RubyGems and Rust.
  • Security updates bump to the minimum patched version; version updates keep everything current.
  • GitHub presets auto-dismiss low-impact alerts in development dependencies: on by default for public repos, opt-in for private repos.
  • Custom auto-triage rules dismiss, snooze or open PRs for the alerts you choose. They need Code Security on private organization repos.
  • Assigning alerts to people or to Copilot needs a Code Security license.
  • New: reachability analysis shows whether your code calls the vulnerable function. Preview, Enterprise Cloud, JavaScript and TypeScript.

Malware alerts: github.com and GHES 3.22+. Reachability needs no GHAS license during the preview.

per user · github.com

Blocks supported secrets in your pushes to public repositories. Private and internal repos need Secret Protection.

  • Included
  • Public repos only
View details
  • Included
  • Public repos only

A personal safety net for github.com users when they push to public repositories. It is not an organization control.

  • Push protection for users is on by default and blocks pushes of supported secrets to public repositories only.
  • It is a per-user setting: each user can turn it off or bypass a block, and organizations cannot enforce it.
  • A bypass creates no alert unless the repository itself has push protection on, which needs Secret Protection.
  • Secret scanning for partners: when a provider's token leaks in a public repo or on npm, GitHub tells the provider so it can be revoked.

Private and internal repos, org-enforced blocking and bypass alerts: Secret Protection.

Guardrails on how code gets in, and signed proof of what came out.

  • Repository rulesets enforce branch and tag rules, such as required reviews and status checks, with named bypass permissions.

Rulesets: public repos on Free; private repos need Pro, Team or Enterprise Cloud. Push rulesets: Team and up. Attestations for private and internal repos need Enterprise Cloud.
